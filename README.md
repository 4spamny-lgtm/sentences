# 🛠️ 문장 공방

**정답 재현보다 먼저, 내 문장을 꺼내 쓰는 연습.**

한국어 문장·문단을 보고 먼저 내 영어로 말하고 써 본 뒤, 원문과 비교해 건질 표현을 골라내고, 그 표현을 다른 상황에 바꿔 써 보는 영어 출력 연습 도구입니다. 서버 없이 HTML 파일 하나로 동작하며, 모든 데이터는 사용하는 브라우저에만 저장됩니다.

👉 **바로 쓰기:** https://아이디.github.io/저장소이름/

---

## 주요 기능

### 🗂️ 문장 훈련
정답 문장을 정확히 익히는 반복 훈련입니다.
- **실시간 타이핑형** — 한 글자씩 맞는지 바로 확인
- **순서대로 클릭형** — 섞인 단어를 순서대로 조립
- **플래시카드형** — 한국어를 보고 떠올린 뒤 뒤집어 확인

### ✍️ 자유작문형
이 앱의 중심 기능입니다. 한 문제를 네 단계로 진행합니다.
1. **내 문장 쓰기** — 한국어만 보고 먼저 내 영어로 표현 (문단도 가능)
2. **원문과 비교** — 내가 안 쓴 원문 단어(노란색)와 원문에 없는 내 단어(빨간색)를 표시
3. **바꿔 말하기** — 골라낸 핵심표현이나 미션으로 원문과 다른 상황의 문장 만들기
4. **원문 타이핑** — 가려진 원문을 떠올려 정확히 재현하며 마무리

각 단계에서 ChatGPT·Claude 등에 붙여 넣을 **AI 첨삭 프롬프트**를 만들어 줍니다. (앱이 AI를 직접 호출하지는 않습니다.)

### 🗝️ 핵심표현 보관함
공부하다 건진 표현과 예문을 모아 둡니다. 골라서 AI 연습 프롬프트나 혼합 테스트 프롬프트를 만들 수 있고, 예문만으로 다시 훈련할 수도 있습니다. CSV로 내보내 Anki 같은 간격 반복 앱에서 복습하기 좋습니다.

### ⭐ 즐겨찾기
어려웠던 문장·문단에 별표를 눌러 모아 두고 따로 복습합니다.

### ▶ 이어서 하기
문장 데이터 / 즐겨찾기 / 핵심표현 목록마다 진행 위치를 따로 저장합니다. 긴 CSV도 매일 조금씩 이어서 풀 수 있고, 복습을 하다 돌아와도 원래 위치가 남아 있습니다.

### 📊 오답 로그 & 심층 분석 (선택)
AI 첨삭 결과를 붙여 넣으면 오류 태그별로 쌓이고, 30건 정도 모이면 반복되는 약점을 분석하는 프롬프트를 만들어 줍니다. 평소보다는 가끔 점검용으로 쓰는 것을 권합니다.

### 🔊 음성 재생
기기에 내장된 음성으로 원문을 읽어 줍니다. 원하면 Google Cloud Text-to-Speech API 키를 넣어 더 자연스러운 음성을 쓸 수 있습니다.

## 학습 데이터(CSV) 형식

엑셀이나 메모장에서 **UTF-8**로 저장한 CSV를 불러오거나, 입력창에 직접 붙여 넣습니다.

### 기본: 한국어, 영어
```csv
나는 커피를 매일 마신다,I drink coffee every morning.
그는 어제 학교에 갔다,He went to school yesterday.
```

### 문단: 칸 전체를 큰따옴표로 감싸기
칸 안에서 줄바꿈이 가능하고, 줄바꿈은 화면에 그대로 보입니다. (채점할 때만 한 줄로 합쳐 비교합니다.)
```csv
"오늘 아침에 늦잠을 잤어.
알람을 못 들었나 봐.","I overslept this morning.
I guess I didn't hear my alarm."
```

### 바꿔 말하기 미션: 머리글 + 3번째 칸
첫 줄에 머리글을 달고, 3번째 칸 이름에 `미션` 또는 `바꿔`를 넣으면 미션으로 읽습니다.
```csv
한국어,영어,바꿔 말하기
"친구랑 2시에 만나기로 했는데
나는 3시인 줄 알았어.","I was supposed to meet my friend at 2,
but I thought it was at 3.","'be supposed to'를 써서, 이번 주에 하기로 했는데 못 한 일 말해 보기"
```
미션에는 정답 표현이 들어 있는 경우가 많아서, 문장 훈련에서는 문제를 완성한 뒤에, 자유작문에서는 원문 비교 다음 단계에서만 보입니다.

### 머리글 규칙
- 첫 줄 첫 칸이 `한국어`, `한글`, `ko`, `korean`이면 머리글로 보고 건너뜁니다.
- 머리글 3번째 칸 이후는 이름으로 역할을 정합니다. `미션`·`바꿔` → 미션, `후리가나` → 후리가나, 그 밖의 이름 → 무시
- 머리글이 없으면 3번째 칸은 후리가나로 읽습니다.
- 여러 CSV를 합칠 때는 **맨 위 머리글 하나만** 남기세요. 중간에 남은 머리글은 문제 하나로 들어갑니다.

### 일본어 후리가나 (선택)
`한글|문장|후리가나` 형식으로, 후리가나는 `漢字[かんじ]`처럼 적습니다.

## 데이터 저장에 관해

- 즐겨찾기, 핵심표현, 오답 로그, 진행 기록은 모두 **이 브라우저의 localStorage**에 저장됩니다. 서버로 전송되지 않습니다.
- 저장 공간은 **기기·브라우저·주소마다 따로**입니다. 컴퓨터와 태블릿의 데이터는 서로 공유되지 않고, 파일을 직접 열 때와 웹 주소로 열 때도 따로 저장됩니다.
- 브라우저 데이터를 지우면 함께 사라지므로, 각 카드의 **⬇ CSV 저장**으로 가끔 백업해 두세요. 다른 기기나 주소로 옮길 때는 **⬆ CSV 불러오기**로 가져옵니다.

## Google Cloud TTS를 쓸 때

- API 키는 코드에 들어 있지 않고 각자 브라우저에만 저장됩니다. **키를 코드에 직접 적어 올리지 마세요.**
- Google Cloud 콘솔에서 키를 **HTTP 리퍼러 제한**으로 이 사이트 주소에서만 쓸 수 있게 해 두면 안전합니다.

## 추천 학습 루틴 (하루 30~40분)

1. **복습** — Anki 등에서 전날까지 골라낸 핵심표현 복습
2. **새 문단 2개** (자유작문형, `순서대로` 출제)
   - 한국어를 보고 **소리 내어 말하기** → 말한 그대로 적기
   - 원문과 비교해 몰랐던 표현 **1~3개만** 핵심표현으로 저장
   - 바꿔 말하기 미션 → 원문 타이핑 → 🔊 원문 들으며 쉐도잉
   - 어려웠던 문단은 ⭐ 별표
3. **1분 말하기** — 오늘 건진 표현 하나를 넣어 오늘 하루 이야기하기

일주일에 한 번은 별표한 문단만 다시 해 보고, 핵심표현 CSV를 Anki로 옮깁니다. 원문을 토씨 그대로 재현하는 것보다, 골라낸 표현이 다른 상황에서 자연스럽게 나오는지가 목표입니다.

## 배포

`index.html` 파일 하나로 동작합니다. GitHub 저장소의 **Settings → Pages**에서 Source를 `Deploy from a branch`, Branch를 `main` / `(root)`로 설정하면 위 주소로 배포됩니다.
